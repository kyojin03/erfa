# Changelog

## 1.0.0 - 2026-08-25

- Built the React and TypeScript eRFA application for GitHub Pages.
- Added the Google Apps Script HTTP/JSON backend, Sheets schema initializer, Drive attachment storage, Gmail notifications, and append-only audit logging.
- Added Google ID-token authentication, capability-based authorization, resource access checks, and self-approval prevention.
- Added configurable users, departments, and approval matrix administration.
- Added requester, approver, and administrator dashboards; RFA create, draft, submit, return, resubmit, disapprove, approve, implementation, and close workflows.
- Added institutional print styling and electronic approval history.
- Added automated workflow tests, deployment workflow, and operator documentation.
